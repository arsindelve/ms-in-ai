## Layout

Each course folder follows the same shape:

```
CSCI-513/
├── README.md          course overview, instructor, assignment index
├── Syllabus.pdf       the syllabus as distributed
├── AssignmentTwo/     one folder per assignment: the prompt PDF,
└── AssignmentThree/   the source, and any data files it reads
```

Assignment folders keep the original prompt PDF alongside the code, so each one stands
on its own — you can read what was asked and what was turned in without leaving the
folder.
